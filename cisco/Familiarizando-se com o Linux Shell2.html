Concluída Laboratório - Use um Scanner de Porta para detectar Portas Abertas

Objetivos

Use o Nmap, um scanner de portas e uma ferramenta de mapeamento de rede, para detectar portas abertas.

Histórico/Cenário

O Network Mapper, ou Nmap, é um utilitário de código aberto usado para descoberta de rede e auditoria de segurança. Uma tarefa comum é verificar máquinas locais para determinar possíveis vulnerabilidades, incluindo portas abertas e não gerenciadas. Todas as estações de trabalho exigem serviços e portas abertas para se comunicar e executar tarefas como imprimir, compartilhar um arquivo ou navegar na Web. Os administradores também usam o Nmap para monitorar hosts ou gerenciar agendamentos de atualizações de serviços. O Nmap determina quais hosts estão disponíveis em uma rede, quais serviços, sistemas operacionais e filtros de pacotes ou firewalls estão sendo executados. Neste laboratório, você usará o Nmap em seu ambiente de VM para detectar portas abertas.

Introdução às portas TCP/UDP

Toda comunicação que acontece pela Internet é trocada usando portas. Cada host IP pode usar dois tipos de portas: TCP e UDP. Pode haver até 65.535 de cada um para qualquer endereço IP.

Os serviços que se conectam à Internet (como navegadores da Web, clientes de e-mail e serviços de transferência de arquivos) usam portas específicas para receber informações. Portanto, cada conexão lógica recebe um número específico. O número da porta também identifica em qual porta ela deve enviar ou receber tráfego durante a comunicação. A IANA atribuiu os números de porta oficial e dividiu essas portas em três subcategorias:

·  Portas bem conhecidas (0-1023)

·  Portas registradas (1024 - 49,151)

·  Portas Dinâmicas/Privadas (49,152 - 65,535)

A seguir, são listadas portas comuns:

20 - File Transfer Protocol - Dados (FTP-DATA)

21 - File Transfer Protocol - Controle (FTP)

22 - Secure Shell (SSH)

23 - Telnet (TELNET)

25 - Simple Mail Transfer Protocol (SMTP)

53 - Domain Name System (DNS)

67 - Dynamic Host Configuration Protocol v4 (DHCPv4 - Cliente para o Servidor)

68 - Dynamic Host Configuration Protocol v4 (DHCPv4 - Servidor para o Cliente)

69 - Trivial File Transfer Protocol (TFTP)

80 - Hypertext Transfer Protocol (HTTP)

Segurança de Portas Lógicas

Cada porta lógica está sujeita a uma ameaça e apresenta uma vulnerabilidade a um sistema, mas algumas das portas usadas com frequência recebem muita atenção dos invasores. Mais de 75% de todos os ataques cibernéticos envolvem apenas algumas portas comuns. Os invasores examinam sistemas para identificar portas abertas em um sistema de destino. Perguntas:

Quais portas TCP estão abertas?

Área de Resposta

Portas 22, 23 e 631

Forneça uma descrição do serviço associado a cada porta aberta.

Área de Resposta

A porta 22 - SSH (Secure Shell) é um protocolo de administração remota usado para controlar e modificar um servidor remoto pela Internet. O SSH autentica o usuário remoto e usa criptografia para criptografar todas as comunicações de e para o servidor remoto. Porta 23 - Telnet fornece uma interface de linha de comando para comunicação com um servidor remoto e transmite usando texto não criptografado (não há criptografia) Porta 631 - CUPS permite que um computador atue como um servidor de impressão. Um sistema executando o CUPS pode aceitar trabalhos de impressão de clientes e enviá-los para a impressora apropriada. O CUPS usa IPP (Internet Printing Protocol).

Pesquise as vulnerabilidades associadas a cada uma dessas portas abertas.

Área de Resposta

As respostas podem variar. Um usuário não autorizado só precisa do seu nome de usuário e senha para obter acesso a um servidor com uma porta SSH aberta. Você pode ver muitas tentativas de fazer login no servidor com logins padrão ou comuns para obter acesso. Outros alvos comuns são as portas 22 e 23 (SSH) e (Telnet). Essas portas são projetadas para fornecer acesso remoto autorizado a um host IP. A porta 23 é essencialmente insegura porque os dados são transferidos em texto sem formatação. A porta 22 é muito mais segura e é preferível ao se conectar a um host remoto. Essas portas podem ser utilizadas por criminosos digitais para realizar os seguintes tipos de atividades mal-intencionadas. - Obtenha acesso remoto autorizado a um host. - Plante backdoors e outros tipos de códigos mal-intencionados. - Visualize dados confidenciais e credenciais. - Realize um ataque man-in-the-middle (homem-no-meio). - Impacto na disponibilidade de outros serviços de host. A porta UDP 631 é um protocolo popular em redes TCP/IP. O termo CUPS (Common UNIX Printing System) é um serviço de impressão de rede modular para hosts Linux que permite que um computador atue como um servidor de impressão. O UPS consiste em um spooler e agendador de impressão, um sistema de filtro que converte os dados de impressão em um formato que a impressora entenderá e um sistema de back-end que envia esses dados para o dispositivo de impressão. Um usuário não autorizado pode executar comandos arbitrários com os privilégios do daemon do CUPS. Além disso, um DoS remoto pode fazer o servidor não responder.

Perguntas:

Quais portas UDP estão abertas?

Área de Resposta

Portas 68, 631 e 5353

Descreva a finalidade dos serviços UDP associados a cada porta.

Área de Resposta

As Portas 67 e 68 fornecem serviços de Dynamic Host Configuration Protocol (DHCP) cliente-servidor. O DHCP é um protocolo de gerenciamento de rede usado em redes de Internet Protocol (IP). Ele atribui dinamicamente um endereço IP e outros parâmetros de configuração de rede ao host da rede. Essas informações são necessárias para que os hosts IP se comuniquem com outros hosts nas redes IP.

Pesquise as vulnerabilidades associadas a cada uma dessas portas abertas.

Área de Resposta

As respostas podem variar. Uma porta 68 aberta fornece serviços de Dynamic Host Configuration Protocol (DHCP). Essa porta permite que hackers interrompam o endereçamento de rede dinâmico e pode ser usada para falsificação de rede e execução remota de código. Uma porta 631 aberta permite que invasores digitais causem uma negação de serviço e possivelmente executem códigos arbitrários. Uma porta 5353 aberta é usada pelo sistema de Multicast Domain Name System (mDNS) que permite que hosts resolvam nomes de host para endereços IP em redes pequenas que não incluem um servidor de nome. No entanto, se a porta mDNS 5353 for exposta à Internet, os invasores podem consultar o serviço para coletar informações sobre o servidor, bem como iniciar um ataque de DoS falsificando um alvo e inundando a rede com solicitações de mDNS.

Resumo

Portas altamente vulneráveis

Muitas portas devem estar abertas para que um host funcione em um ambiente de computação e comunicação normal. No entanto, essas portas comuns devem ser monitoradas regularmente para garantir que não sejam comprometidas e sejam usadas para atacar uma vítima, fornecer acesso remoto não autorizado ou sejam usadas para invadir um host para participar de um ataque distribuído a outras vítimas.

A porta 21 do TCP é uma das portas mais populares para invasores. Essa porta foi projetada para transmitir e receber arquivos de um host para outro. Os invasores usam essa porta para realizar os seguintes tipos de atividades mal-intencionadas:

·  Transferência, exclusão e modificação não autorizadas de arquivos

·  Transferência não autorizada de códigos ou payloads mal-intencionados

·  Autenticação anônima para hospedar sistemas de arquivos

·  Injetar scripts mal-intencionados como ataques XSS

·  Impacto na disponibilidade de outros serviços de host

Outro alvo comum é a porta 23 (Telnet). Essa porta fornece acesso remoto autorizado a um host IP. Essa porta apresenta uma vulnerabilidade porque os dados transferidos estão em texto sem formatação. Os invasores usam essa porta para realizar os seguintes tipos de atividades mal-intencionadas:

·  Obter acesso remoto não autorizado a um host

·  Plantar backdoors e outros tipos de código mal-intencionado

·  Visualizar credenciais e dados confidenciais

·  Realizar um ataque man-in-the-middle (homem-no-meio).

·  Impacto na disponibilidade de outros serviços de host

Outra porta favorita dos invasores é a porta 53. Essa porta é usada para DNS ou consulta de nomes de domínio ao navegar na Internet ou transferir informações. Essa porta é a rota de saída mais comum para o invasor após um ataque. Como essa porta raramente é monitorada, os invasores usam essa porta para sair após limpar seus arquivos, logs e outras informações para encobrir seus rastros.

A porta mais comum usada pelos invasores é a porta TCP 80. Essa porta transfere páginas da Web entre um servidor Web e o navegador host. Os invasores usam essa porta para realizar os seguintes tipos de atividades mal-intencionadas:

·  Transferência, exclusão e modificação não autorizadas de dados

·  Transferência não autorizada de códigos ou payloads mal-intencionados

·  Injeção de scripts mal-intencionados (como um ataque XSS)

·  Impactar na disponibilidade de outros serviços de host
